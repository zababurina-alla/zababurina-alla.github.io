# Визуальные снимки сайта

Каждый экран × светлая / тёмная тема × 1280 / 375 px на выдуманных данных учебного сервера (`npm run dev:mock`
поднимается сам). Два вида проверок:

1. **Эталон** — снимок окна сравнивается с `__screenshots__/<проект>/<экран>.png`. Порог: отличается больше 0,2 %
   пикселей (каждый — больше 0,2 по цвету) → ошибка.
2. **Белые пятна на тёмной теме** — по разметке (видимый элемент с непрозрачным фоном светлее #f0f0f0 больше 24×24 px)
   и по пикселям снимка (связная почти белая область больше 24×24 px, залитая на треть или белая по половине края).
   Отдельно — **iframe с непрозрачным светлым фоном**: у каждого окошка больше 24×24 px смотрятся пиксели в углах, 3–4
   светлых из 4 — пятно (находка владельца 15.10: кнопка Google режет белую рамку на полосы ниже 24 px, общий поиск её
   не видит). Разрешённые исключения — `ALLOW_WHITE` в `screens.visual.ts` с причиной.

## Запуск

```
npm run visual                                   все снимки и проверки
npm run visual -- --project=dark-375             одна тема и ширина
npm run visual -- -g "платежи"                   один экран
npm run visual:update                            переснять эталоны — ТОЛЬКО после просмотра отличий в отчёте
npm run visual:selftest                          самопроверка: каждая поломка обязана быть поймана
```

Отчёт с отличиями «было / стало / разница» — `tests/visual/.report/index.html`.

**Прогон только на этом компьютере (Windows, ПК владельца):** эталоны сняты здесь; на другой машине шрифты и
сглаживание дают отличия — там эталоны переснимать отдельно.

## Как устроено

- Настройки сайта (`config.json`, `config.local.json`) подменяются на учебный сервер: в `public/config.json` адрес
  ЖИВОГО API, и без подмены dev:mock ходил бы в таблицу мамы. Вся внешняя сеть заблокирована.
- Вход — учебный (`idToken: "mock:qa-visual@example.invalid"`), окно Google не открывается; сеанс кладётся в
  localStorage, как это делает сайт.
- Время — 14.10.2026 10:00 по Киеву и идёт: браузер — `page.clock.install` + `resume` (остановленные часы замораживают
  анимации появления GSAP), учебный сервер — `fixed-date.mjs` через `NODE_OPTIONS`.
- Один повтор упавшего теста (занятый ПК: браузер изредка не открывает страницу за 60 с); прошедший со второй попытки
  виден в отчёте как flaky.
- Без сети: всё внешнее блокируется; скрипт входа Google заменён заглушкой — кнопка в iframe со светлым документом,
  как у настоящей (так воспроизводится белый прямоугольник при `color-scheme: dark` у контейнера, 15.10.2026).
- Движение выключено (`reducedMotion: 'reduce'`, анимации в снимке — `disabled`).

## Самопроверка

`VISUAL_BREAK=<поломка>` вставляет CSS с начала загрузки страницы (Chrome решает заливку iframe при его загрузке):
`white-login` (контейнер кнопки Google в тёмной схеме — причина находки владельца), `shift-8px` (отступ сверху +8 px),
`button-color` (цвет кнопок). Каждая поломка обязана дать красный прогон.

Отладка: `VISUAL_TIMING=1` — время шагов на экран; `VISUAL_SHOT=1` — снимок каждого экрана в `.out/shot-*.png`.
