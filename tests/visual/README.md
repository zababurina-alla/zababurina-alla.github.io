# Визуальные снимки сайта

Каждый экран × светлая / тёмная тема × 1280 / 375 px на выдуманных данных учебного сервера (`npm run dev:mock`
поднимается сам). Два вида проверок:

1. **Эталон** — снимок окна сравнивается с `__screenshots__/<проект>/<экран>.png`. Порог: отличается больше 0,2 %
   пикселей (каждый — больше 0,2 по цвету) → ошибка.
2. **Белые пятна на тёмной теме** — по разметке (видимый элемент с непрозрачным фоном светлее #f0f0f0 больше 24×24 px)
   и по пикселям снимка (связная почти белая область больше 24×24 px — видит и iframe кнопки Google). Разрешённые
   исключения — `ALLOW_WHITE` в `screens.visual.ts` с причиной.

## Запуск

```
npm run visual                                   все снимки и проверки
npm run visual -- --project=dark-375             одна тема и ширина
npm run visual -- -g "платежи"                   один экран
npm run visual:update                            переснять эталоны — ТОЛЬКО после просмотра отличий в отчёте
npm run visual:selftest                          самопроверка: каждая поломка обязана быть поймана
```

Отчёт с отличиями «было / стало / разница» — `tests/visual/.report/index.html`.

**Прогон только на этом компьютере (Windows, ПК владельца):** эталоны сняты здесь; на другой машине шрифты и
сглаживание дают отличия — там эталоны переснимать отдельно.

## Как устроено

- Вход — учебный (`idToken: "mock:qa-visual@example.invalid"`), окно Google не открывается; сеанс кладётся в
  localStorage, как это делает сайт.
- Время заморожено: браузер — `page.clock.setFixedTime`, учебный сервер — `fixed-date.mjs` через `NODE_OPTIONS`
  (выдуманные данные рассчитаны на 14.10.2026).
- Без сети: всё внешнее блокируется; скрипт входа Google заменён заглушкой — кнопка в iframe со светлым документом,
  как у настоящей (так воспроизводится белый прямоугольник при `color-scheme: dark` у контейнера, 15.10.2026).
- Движение выключено (`reducedMotion: 'reduce'`, анимации в снимке — `disabled`).

## Самопроверка

`VISUAL_BREAK=<поломка>` вставляет CSS после загрузки экрана: `white-login` (контейнер кнопки Google в тёмной схеме —
причина находки владельца), `shift-8px` (отступ сверху +8 px), `button-color` (цвет кнопок). Каждая поломка обязана
дать красный прогон.
