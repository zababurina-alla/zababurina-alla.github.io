# Правила проекта «Бухгалтерия» (mama-cabinet)

Главнее глобальных правил. Где мы и что проверено — `docs/журнал.md`, очереди отделов — `docs/отделы/`.

## Вид сайта — только по эталону

- Эталон вида — **[DESIGN.md](DESIGN.md)** (утверждён владельцем 18.10.2026): отступы шагом 4, радиусы 12 и 20,
  шрифты 15/17/20/26/36/44, начертания 400/500/600, палитра с ролями, список «никогда», референсы.
- Значения — только токены `src/styles/tokens.css`. Своё число вне шкалы роняет `npm test`
  (`scripts/design-scale.test.ts`). Не переведённые ещё файлы держит «храповик» `scripts/design-baseline.json`:
  нарушений не больше базы; стало меньше — опустить базу `npm run design -- --baseline` тем же коммитом.
- Перевёл экран целиком — добавь его CSS в `CONVERTED` в `scripts/design-scale.test.ts`.

## Приёмка вида (для любой проверяющей сессии)

Правило и чек-лист — **[docs/дизайн/приёмка-вида.md](docs/дизайн/приёмка-вида.md)**. Коротко:

1. Снимки на собранном сайте, **375 и 1280**.
2. Найди **минимум 5 расхождений с DESIGN.md** на экран, каждое — с числом и пунктом эталона.
3. **«Всё отлично» без списка не принимается.**
4. Числа машин до слова «принято»: `npm test`, `npm run design`, `node scripts/design-dom-audit.mjs`.
5. «Готово» — только после того, как сам посмотрел снимки глазами и сверил с DESIGN.md.
