# Сверка — рабочий кабинет бухгалтера

Веб-кабинет бухгалтера поверх системы «Мама CRM» (Google-таблица + Apps Script + Telegram-бот).
Таблица — единственный источник правды: сайт читает и пишет её только через API, своей базы у сайта нет.
Сервер (JSON-API в Apps Script) делает команда «Мамы CRM»; здесь только сайт и контракт API (`docs/api-contract.md`).

Задание и этапы — `ПРОМТ-НОВОЙ-СЕССИИ.md` (лежит рядом, в репозиторий не входит: там личные сведения). Исходный бриф — `D:\МАМА ТАБЛИЦА\docs\сайт\бриф.md`.

## Команды

| Команда | Что делает |
|---|---|
| `npm install` | поставить зависимости (нужен Node ≥ 22.13) |
| `npm run dev` | открыть сайт локально с автообновлением |
| `npm run build` | проверка типов + сборка в `dist/` |
| `npm run preview` | открыть собранный `dist/` |
| `npm run lint` | проверка кода (ESLint) |
| `npm run typecheck` | проверка типов TypeScript |
| `npm test` | тесты (Vitest), включая корпуса читалок: суммы, поиск, даты, задачи |
| `npm run contrast` | таблица контраста цветов → `docs/контраст.md` |

## Стек и почему

- **Vite + TypeScript strict** — быстрая сборка статического сайта для GitHub Pages, строгие типы ловят ошибки
  в суммах и датах до запуска.
- **React 19** — самая распространённая основа: любой следующей сессии и любому разработчику проще поддерживать;
  у GSAP есть официальный слой для React (`useGSAP`, Flip для перехода «строка → карточка»).
- **Маршруты через `#/`** (свой модуль `src/router.ts`, ~40 строк, без библиотеки) — GitHub Pages отдаёт один
  `index.html`, обновление страницы не даёт 404.
- **Vitest + jsdom** — тесты корпусов (поиск клиента, разбор сумм и дат) и контраста цветов.
- Без сервера и без бэкенда в репозитории.

## Безопасность

Репозиторий публичный. Здесь **нельзя** хранить данные клиентов, ключи, адреса почты, выгрузки таблицы
(`.gitignore` закрывает `.env*`, `*.xlsx`, `data/`). До готовности API сайт работает на выдуманных данных.

## Режим отладки

`http://localhost:5179/?debug=1` или `Ctrl+Shift+D`: правки «из таблицы» и «через бота», обрыв связи, отказ сервера,
счётчики ступеней записи. Витрина значков — `#/icons`. Командная строка — `Ctrl+K`, записать платёж — `Alt+N`.
