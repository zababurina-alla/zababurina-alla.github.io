## Чьё это: хозяин — «Дизайн»

| Компонент | Файлы | Что важно знать |
|---|---|---|
| **Tabs** — переключатель с подложкой | `src/ui/kit.tsx` (`Tabs`), `src/styles/ui.css` (`.tabs`, `.tabs__tab`, `.tabs__ind`) | Подложка считается по дробным размерам кнопки (`getBoundingClientRect`): целые `offset*` на масштабе Windows 125 % сдвигали её на полпикселя. В одну строку высота подложки = высота полосы минус 3 + 3 px, она по центру. При переносе подложка встаёт на строку выбранного пункта. Пересчёт идёт через `ResizeObserver` (догрузился шрифт, сменилось окно). Если не помещается — классы `has-more-start` / `has-more-end`, край затухает через `mask-image`, выбранный пункт прокручивается в видимую часть. В тёмной теме подложка светлее полосы. |
| **Полосы** — вкладки, сегменты, фишки | `.tabs`, `.seg`, `.seg--fill`, `.chips` в `src/styles/ui.css` и на экранах | Правило: подложка внутри полосы и по центру ±1 px; последний пункт виден целиком или край явно затухает. Карточка клиента: вкладки делят ширину, на узком листе переносятся (`.cp > .tabs`, `clients.css`). |
| **Касание 44 px** | `src/styles/touch.css` (подключён в `app.css` перед `print.css`) | Действует только при `(hover: none)` или `(pointer: coarse)`, десктоп не меняется. Видимые маленькие кнопки, вкладки, фишки и поля — 44 px. Значки и ссылки внутри строк — зона нажатия 44 без роста вида: прозрачная рамка плюс отрицательные поля. `:root` впереди — чтобы вес был выше правил компонентов. |
| **layout-audit** — скрипт замеров | `scripts/layout-audit.mjs` | Новый дизайнер им пользуется. Свои проверки деталей он держит в `scripts/detail-audit.mjs`. |

Не моё, не брать:
- помощник (`.ai-*`) — ведёт новый дизайнер;
- карточка клиента, поповеры, начисления, пароль — находки нового дизайнера.

## Правила layout-audit

1. Мерить так же, как принимает «Пользователь»: `npm run build`, затем `npm run preview -- --port 4180` (конфигурация `cabinet-dist`).
   - «Было» — сборка main во временном worktree; `node_modules` подключить ссылкой-junction.
   - «Стало» — своя сборка.
   - Оба замера одним файлом скрипта. Поправил детектор — перемерь и «было».
2. Запуск:
   - `node scripts/layout-audit.mjs http://localhost:4180/ [--json файл] [--only экраны]` — 17 экранов и окон × 1280 / 1024 / 375 × светлая / тёмная.
     - Колонки: пустоты, высоты, колесо, подписи, вбок, касание (только 375), полосы.
     - 375 — телефон с касанием (`hasTouch`).
   - `… --print` — печать A4 на 703 и 794 px: обрезано, интерфейс на бумаге, пусто справа, листов.
   - `… --checks`:
     - лента чата крутится колесом;
     - кнопки ленты не под краем окна;
     - лента над уведомлением в двух переписках;
     - вкладки карточки на масштабе 125 %;
     - вкладки «Сроков» на телефоне (375/320 × 2 темы × 100/125 %);
     - меню целиком на 1280×800 / 1280×720 / 1024×768;
     - два уведомления подряд.
   - `--strict` — код 1 при любой находке.
3. Замер после нажатия — только когда анимация закончилась: подложка вкладок едет 0,55 с. Ждать дольше перехода или по состоянию страницы, не по часам.
4. Масштаб экрана владельца — 125 %: полпиксельные сдвиги проверять с `deviceScaleFactor: 1.25`.
5. Что не считается находкой, описано в памятке:
   - промежуток между колонками строки;
   - низ страницы после последнего блока;
   - столбики графиков;
   - липкая колонка;
   - текст для чтеца экрана.
6. Задуманные пустоты сейчас (6): воздух справа от заставки «Сегодня» 1280; низ колонки чатов «Входящих» и переписки на 1280 при 4 чатах.
7. После проверок закрывать браузеры и серверы: headless 0, Chrome ms-playwright 0, свои порты 0.
   - Аргументы вида `'#/…'` в Git Bash — с `MSYS_NO_PATHCONV=1`.

- **Вкладки «Сроков» на 375 переносятся в две строки** — замечание «Качества» на main `8a8b9d6`.
  - `--checks`: «в две строки» 32 из 32 (8 видов × 4 вкладки). Подложка и край при этом в порядке.
  - Причина — общее правило в `src/styles/ui.css`: на ≤ 559 px любая `.tabs` переносится (`flex-wrap: wrap`).
  - Вкладки вместе — 440 px при 295 доступных на 375 и 240 на 320. Даже ужатые до шрифта 14 px они в одну строку не лягут.
  - Готовый вариант на ветке `claude/design-deadlines-tabs-375-draft` (`0f57950`):
    - на ≤ 559 px `.panel__head > .tabs` — одна строка с прокруткой вбок, `scroll-padding-inline: 3px`, без `scroll-snap` (он возвращал полосу назад);
    - край затухает, выбранный пункт встаёт в видимую часть;
    - замер: в две строки 32 → 0, срезано 0, подложка мимо 0; полный замер без регрессий; 2 эталона «Сроки» 375 обновлены.
  - Задачу отменили до свежей сессии. Решить: брать черновик или другой путь, например короче подписи на телефоне.
- **«Клиенты» на 375:** вкладки «Тип клиента» переносятся в две ровные строки — так было сделано нарочно. Если владелец сочтёт и это кривым — тот же подход, что для «Сроков».
