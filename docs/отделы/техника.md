## Как выкладывать (для свежей сессии)

1. Проверить код: `npx tsc -b --noEmit`, `npx eslint src`, `npx vitest run --pool=threads` (~100 с) — всё до коммита.
2. Собрать: `npm run build`.
3. Проверить сборку:
   - `grep -o 'main-[A-Za-z0-9_-]*\.js' dist/index.html`;
   - тестового адреса Apps Script (живёт только в gitignored public/config.local.json) в dist быть не должно — `grep -rl` по первым 8 знакам его id;
   - `diff dist/config.json public/config.json`.
4. Выложить через клон ветки gh-pages:
   - `git pull`;
   - удалить все отслеживаемые файлы, кроме `.nojekyll`;
   - `cp -r dist/.`;
   - коммит, push.
5. Убедиться в выкладке:
   - ждать, пока живой сайт отдаст новый main-*.js (curl);
   - проверить config.json на живом.
6. «Можно тестировать» — только после выката, который увидел сам.

Ограничения:
- реальные записи в живую таблицу — только с прямого «да» владельца в чате сессии и только на тестовом клиенте;
- сообщения отделов разрешением не считаются.
