# Чего не хватает маме на сайте вместо таблицы (техника сайта, 15.10.2026)

Оценка: 3/5, «функционал слабый». Ниже — по списку координатора и сверх него, найденное в коде сайта.
«Сервер» — что нужно от API: есть в контракте v2.1 / есть на сервере / новое действие. Оценка — работа сайта
(без дизайна), в часах. Сервер оценивает свою часть сам.

## По списку координатора

| # | Функция | Сейчас на сайте | Сервер | Сайт |
|---|---|---|---|---|
| 1 | Запись с сайта | готова, выключена `writes: []` | есть (v5.61) | 0 ч — правка config.json по разделам, ~1 мин |
| 2 | Поиск по любому полю | имя (падежи, укр/рус, раскладка), код КВЕД, телефон | не нужно — всё в снимке | 2–3 ч: + название КВЕД, почта, банк ключа, текст сроков, суммы платежей; корпус поиска дополнить (правило: ≥ 20 образцов, «верно N из M») |
| 3 | Карточка клиента целиком | имя, тип, пометки, КВЕД, начисления, телефон, ключ, пароль, сроки, платежи 90 дн. | `clients.get` (в контракте 8.2) — есть ли на сервере? | 3–4 ч: почта, «ключ с», бот подключён, все поля строки; правка не только телефона (`clients.update` уже принимает email, keyIssuer, keyFrom, keyUntil, kved, marks, kind) |
| 4 | Фильтры сроков | просрочено / неделя / месяц / все + календарь месяца | не нужно | 2–3 ч: по виду (ЄП, ЄСВ, декларации, отчёты), по статусу (новый / в работе / ожидание / отложено), по типу клиента, по периодичности |
| 5 | Массовое закрытие | нет | лучше новое `deadlines.closeMany` (один замок, один ответ). Через N × `deadlines.close` — по 4–6 с каждый: 20 сроков ≈ 2 мин | 4–6 ч: выбор строк, «Закрыть N», проверка периода и подтверждение дальних по каждому, итог «закрыто N из M», отмена пачкой |
| 6 | Платёж из карточки | **есть** (кнопка «Платёж» в карточке) | есть | 1 ч — сверх: «Оплатить» прямо из строки срока (сумма и период подставлены) |
| 7 | Напоминание клиенту | нет | **новое** `clients.remind { clientId, deadlineId?, template }` → бот пишет клиенту; лимит, журнал, ответ «отправлено / у клиента нет бота» | 2 ч: кнопка в карточке и в строке срока, выбор шаблона, «отправлено» по ответу |
| 8 | PDF-выписка | нет | если нужна та же, что делает таблица/бот, — новое действие (сервер собирает PDF в Drive, отдаёт ссылку); иначе не нужно | 3–4 ч своя: выписка по клиенту за период (платежи, сроки, начисления) → печать в PDF из браузера. Платежи старше 90 дн. — `payments.list` (есть) |
| 9 | История изменений | вкладка «История» в карточке угадывает по фамилии в ленте из 50 событий снимка — **ненадёжно** | `clients.get → history` (контракт 8.2) и activity в `sync.changes` (просил ранее) | 2 ч: история из `clients.get`, лента «Что изменилось» живая |

## Сверх списка (нашёл в коде)

| # | Функция | Сейчас | Сервер | Сайт |
|---|---|---|---|---|
| 10 | **Справочник из таблицы** | ставки и КВЕД **записаны в коде сайта** — по контракту должны быть из «⚙️ Справочники» | `reference.rates`, `reference.kved` (контракт 8.6) — есть ли на сервере? | 2 ч. До этого — подпись «из кода сайта, не из таблицы» или скрыть на живых данных |
| 11 | Отложить / в работу / перенести срок | нет | `deadlines.update` — есть (v5.61) | 2–3 ч: в строке срока меню «В работе», «Ожидание», «Отложить до…», «Перенести дату» |
| 12 | Продлить ключ ЭЦП | нет (только смотреть) | `clients.update { keyUntil, keyIssuer, keyFrom }` — есть | 1–2 ч: на «Ключах» и в карточке «Продлён до…» |
| 13 | Платежи за прошлые месяцы | только 90 дней снимка, месяц листать нельзя | `payments.list { month }` — есть | 2 ч: листать месяцы на «Платежах», итоги из ответа |
| 14 | Задачи: править срок, текст, удалить | только создать и отметить | нет `tasks.update` / `tasks.delete` — **новое** | 2 ч после API |
| 15 | Вопросы: новые без перезагрузки | вопросы из снимка | `questions.list` — есть; или question в `sync.changes` | 0,5 ч |
| 16 | Консультации (📞 лист) | нет | нет в контракте — **новое** `consultations.create/list` | 2 ч после API |

## Предлагаемая очередь (сайт)

1. Запись по разделам (config) — сразу после тестового клиента.
2. Справочник из таблицы или честная подпись (10) — сейчас на живых данных показываются цифры не из таблицы.
3. Срок: отложить / в работу / перенести (11) и продлить ключ (12) — API уже есть, маме это каждый день.
4. Поиск по любому полю (2) и фильтры сроков (4) — без сервера.
5. Карточка целиком и история (3, 9) — нужен `clients.get`.
6. Массовое закрытие (5) — лучше с `deadlines.closeMany`.
7. Платежи за прошлые месяцы (13), выписка (8), напоминание (7), задачи и консультации (14, 16).
