# Премиальные детали — предложения дизайна (16.10.2026)

Задача владельца, п. 6: «предложи 3–5 новых премиальных деталей сам». Каждая — небольшая, с понятной пользой для мамы,
без новых данных или с минимальными. Оценка — сколько работы у дизайна и у техники.

## 1. Тактильный отклик на телефоне

При закрытии срока и записи платежа телефон коротко вздрагивает (`navigator.vibrate(12)`), вместе со звуком.
Подтверждение «получилось» без взгляда на экран. Подчиняется тому же переключателю звука («выкл» и «ночью тихо»).
Работает на Android, на iPhone браузер вибрацию не даёт — там остаётся звук.
**Работа:** дизайн — полдня (lib/sound.ts + вызовы рядом с play); техника — нет.

## 2. «Пульс месяца» на «Сроках»

Тонкая полоса под заголовком: «Октябрь: закрыто 18 из 26» и заполнение цветом «море». Закрыла срок — полоса
подросла с пружиной. Все сроки месяца закрыты — короткий тихий «финал»: галочка и «Месяц сдан».
Мама видит, сколько осталось, и чувствует движение к концу месяца.
**Работа:** дизайн — день; техника — число закрытых за месяц (сейчас «Закрыто сегодня» — только за день).

## 3. «Что изменилось, пока вас не было»

Открыла кабинет после перерыва — строки, которые изменились без неё (оплатил клиент через бота, Дмитрий поправил
в таблице), 3 секунды подсвечены мягким пшеничным, с подписью источника: «из Telegram», «из таблицы». Счётчики
и суммы перекатываются (RollingNumber уже есть). Не надо гадать, что нового.
**Работа:** дизайн — день; техника — время последнего визита (в браузере) и источник изменения (уже есть в журнале).

## 4. Тёплый вечер

Фон «бумаги» незаметно меняется по времени суток: утром чуть холоднее (свет «море» сильнее), после 18:00 —
теплее (пшеничный отсвет сильнее). Только оттенок подсветки фона, текст и контраст не меняются. Кабинет «живой»,
вечером глазам спокойнее.
**Работа:** дизайн — полдня (две переменные отсвета в tokens.css + класс по часу); техника — нет.

## 5. Шпаргалка клавиш

Клавиша «?» (или пункт в «Помощи») показывает маленькую карточку: Ctrl K — найти клиента, Alt N — записать платёж,
F1 — помощь, / — поиск на «Клиентах», Esc — закрыть окно. Для мамы за ноутбуком — быстрее, чем мышью.
**Работа:** дизайн — полдня; техника — повесить «?» рядом с F1.

## Рекомендация

Первыми — 1 и 2: короткие, полезные каждый день, видны сразу. 3 — самая ценная, но нужна техника. 4 и 5 — «на сладкое».
