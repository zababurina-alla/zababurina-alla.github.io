# Дизайн v2: детали, из которых собирается кабинет

Отдел «Дизайн», 15.10.2026. Ориентир по ощущению — «Сверка рейсов» (sverka-reysov.github.io), без персонажа.
Правило как там: **любой новый экран собирается только из деталей ниже**, без своих цветов, отступов, теней и
`cubic-bezier`. Нужна деталь нового вида — сделать простой, на токенах, и написать отделу «Дизайн» через основную
сессию; дизайн доведёт.

## Само собой, без пометок

- Строки `.dtable__row` и `.ctable__row` появляются по очереди, шаг 30 мс (первые 20) — достаточно ставить `style="--i: N"`.
- Новые строки и записи из таблицы/бота — класс `is-fresh` (подсветка 2,6 с, без сдвига).
- Свет за курсором — у `.tally` и `.hero` (`src/ui/fx.ts`, один слушатель на документ). Их `::before/::after` заняты светом.
- Значки оживают при наведении по `data-icon` (ставит `<Icon>` сам): меню, кнопки, рисунки пустых мест.
- Закрытие срока: галочка заливается пружиной, кольцо расходится, плашка улетает в видимый `[data-closed-counter]`.
- `prefers-reduced-motion` — всё то же без перемещений (низ `fx.css`, нули в `tokens.css`).

## Тени, движение — только токены

Глубина: `--shadow-1` лежит, `--shadow-2` поднят (наведение), `--shadow-3` окно.
Кривые: `--ease-out`, `--spring` (перелёт 5 %), `--spring-pop` (12 %, отклик на нажатие), `--spring-soft` (2 %, окна).
Длительности: `--dur-press` 120, `--dur-fast` 150, `--dur-base` 220, `--dur-move` 400, `--dur-spring` 550, `--dur-pop` 640 мс.

## Звук

`play(name)` из `src/lib/sound.ts`. Играет **только в ответ на действие человека** (нажатие или клавиша не дальше 5 с) —
событие из таблицы или бота само по себе молчит. Режимы: «вкл» / «ночью тихо» (22:00–7:00, по умолчанию) / «выкл».
Звуки: `saved` (записано), `closed` (срок закрыт), `attention` (нельзя / ошибка), `tick` (выбор фильтра), `incoming`.
