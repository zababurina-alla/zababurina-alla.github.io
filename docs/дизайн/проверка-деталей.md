# Проверка деталей — `scripts/detail-audit.mjs`

Новый дизайнер, 17.10.2026. Владелец сам нашёл: подложка активной вкладки карточки стоит неровно и вылезает за полосу,
«История» срезана правым краем. `layout-audit.mjs` этого не ловил: его проверка «вбок» нарочно пропускает `.tabs, .chips`,
а геометрию подложек он не меряет. Этот скрипт меряет именно детали — каждое число > 0 есть находка.

| Число | Что считает |
|---|---|
| **подложка** | индикатор выбранного (`.tabs__ind`, `.nav__pill`) не совпал с выбранным пунктом > 1 px; вылез за полосу; не по центру полосы по высоте (зазор сверху ≠ снизу > 1 px); срезан краем |
| **срез** | пункт полосы (вкладка, фишка, кнопка) виден не целиком, а явной прокрутки нет: ни видимой полосы прокрутки, ни стрелок, ни затухания края; любая кнопка или метка, видная частично |
| **выбранное** | выбранный пункт (`aria-pressed` / `aria-current` / `aria-selected`) срезан |
| **разнобой** | одинаковые детали (тот же тег и набор классов в том же месте) с разным радиусом, отступом слева/справа, шрифтом; в одном ряду — разной высоты > 1 px |
| **значок** | значок в кнопке / вкладке / пункте не по центру строки текста > 1,5 px |
| **наезд** | текст вылез из своей ячейки сетки > 1 px (в соседнюю колонку или в поле листа) |
| **прыжок** | при переключении вкладок полоса сдвинулась или окно сменило ширину > 1 px; после сужения окна (до 520 / 330 px) подложка не переехала за выбранной вкладкой |
| **противоречие** | в одной строке «через N дн.» и «просрочено M дн.» (данные — передать «Серверу API») |

Виды: 1280×800, 1280×720, 1024×768, 375×812 (телефон с касанием) × светлая / тёмная. Экраны: 21 — все разделы,
каждая вкладка карточки клиента, меню «Действия» срока, окно платежа, новый клиент, Ctrl K.

```
node scripts/detail-audit.mjs http://localhost:5183/            # все 168 видов (~12 мин)
node scripts/detail-audit.mjs <адрес> --only карточка,сроки --views 1280x800-light,375x812-dark
node scripts/detail-audit.mjs <адрес> --json итог.json --strict  # код 1, если хоть одно число > 0
```

## Замер 17.10.2026: было (main 4d7a043) → стало (design/fresh-eyes)

Одна версия скрипта, оба сайта в учебном режиме `?demo=1`, 168 видов.

| Число | Было | Стало |
|---|---|---|
| подложка | 72 | 0 |
| срез | 62 | 0 |
| выбранное | 0 | 0 |
| разнобой | 2 | 2 (ложное, см. ниже) |
| значок | 0 | 0 |
| наезд | 20 | 0 |
| прыжок | 24 | 0 |
| противоречие | 0 | 0 |

Оставшиеся 2 «разнобоя» — «Сегодня» 1024 (свет и тьма): боковые листы стоят плиткой в две колонки, у сетки один ряд,
и скрипт сравнивает их высоты (1088 / 226 / 254). Это раскладка, не брак.

В одном прогоне «стало» был 1 «прыжок» (карточка 1280×800: подложка мимо на 429 px). На занятом ПК замер попал
на середину пружины. Повтор 9 из 9 — 0. Скрипт теперь перед каждым замером ждёт, пока закончатся анимации
(бесконечные пульсации не в счёт).

Ложные следы, проверенные и отброшенные: бледные «Позвонить / Платёж / Действия» поверх названий на снимке всей
страницы (`fullPage`) — в окне их нет (прозрачность 0, наведения нет); «пустой» лист «Задачи на сегодня» — строки ещё
появлялись.

Д-4 действует на любом касании, не только на 375: на планшете с пальцем «Действия» тоже видны всегда, и без этого
правила там был бы тот же разнобой строк (короткое название — кнопка справа, длинное — под ним). Строка с коротким
названием на планшете стала выше примерно на 44 px. Это сделано осознанно.
