## Как включить живые данные (без пересборки)

Сайт при запуске читает `config.json` рядом с собой (в репозитории — `public/config.json`, на сайте — корень ветки `gh-pages`):

```json
{ "apiUrl": "https://script.google.com/macros/s/<DEPLOYMENT_ID>/exec", "writes": ["payments", "tasks"] }
```

- `apiUrl` пустой — выдуманные данные; задан — вход Google и живые данные. `?demo=1` в адресе — всегда выдуманные.
- `writes` — разделы, где запись с сайта уже включена (`payments`, `tasks`, `questions`, `deadlines`, `clients`);
  остальные — только просмотр: кнопки неактивны с подписью «пока в таблице», сверху плашка. `[]` — только просмотр
  везде; ключа нет — запись везде.
- Поменять: правка `config.json` в `gh-pages` (обычный коммит и push) + та же правка в `public/config.json` в `main`.
  GitHub Pages кэширует до 10 мин; сайт берёт файл без кэша браузера.
- Сервер не отдал данные при открытии — экран «Таблица сейчас не отвечает сайту» с текстом сервера и «Повторить»;
  отказ входа — текст на экране входа.
